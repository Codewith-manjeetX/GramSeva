Emergency Helplines

One tap to call — available even without internet in emergency mode. Your GPS location is shared automatically when you press SOS.

What to do in common situations

If police refuses to register FIR
1. Send written FIR to SP by registered post
2. Approach Judicial Magistrate under Sec 156(3)
3. Call NALSA free legal aid: 15100
4. File online complaint at pgportal.gov.in
If you receive an OTP fraud call
1. Hang up immediately — no bank asks for OTP
2. Call Cyber Crime: 1930
3. Check bank account balance immediately
4. Block card if needed via 1800 numbers
If MNREGA wages are delayed
1. File complaint on MNREGA mobile app
2. Contact Block Development Officer
3. File RTI with Programme Officer
4. Call Labour helpline: 1800-11-6090
If ration is not delivered
1. File complaint on NFS portal or Panchayat Portal
2. Contact District Supply Officer
3. File RTI with PDS department
4. Call State Food Helpline
